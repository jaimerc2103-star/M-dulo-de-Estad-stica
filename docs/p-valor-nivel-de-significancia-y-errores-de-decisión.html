18 p-valor, nivel de significancia y errores de decisión

18.1 Concepto teórico

El p-valor es una medida que indica qué tan compatible es la evidencia muestral con la hipótesis nula. Mientras menor sea el p-valor, mayor será la evidencia contra \(H_0\).

18.1.1 Interpretación del p-valor

Si:

\[ p\text{-valor} \leq \alpha \]

se rechaza \(H_0\).

Si:

\[ p\text{-valor} > \alpha \]

no se rechaza \(H_0\).

Es importante señalar que no rechazar \(H_0\) no significa demostrar que \(H_0\) sea verdadera, sino que la evidencia muestral no es suficiente para rechazarla.

18.2 Errores de decisión

18.2.1 Error tipo I

Ocurre cuando se rechaza \(H_0\) siendo verdadera.

\[ P(\text{Error tipo I}) = \alpha \]

18.2.2 Error tipo II

Ocurre cuando no se rechaza \(H_0\) siendo falsa.

\[ P(\text{Error tipo II}) = \beta \]

18.2.3 Potencia de una prueba

La potencia es la probabilidad de rechazar \(H_0\) cuando realmente es falsa:

\[ \text{Potencia}=1-\beta \]

18.3 Ejemplo aplicado

Se evalúa si la media de temperatura de operación de un equipo es igual a 70 °C.

temperatura <- c(71, 72, 69, 70, 73, 72, 71, 70, 74, 72, 71, 73)
temperatura
##  [1] 71 72 69 70 73 72 71 70 74 72 71 73

Hipótesis:

\[ H_0: \mu = 70 \]

\[ H_1: \mu \neq 70 \]

18.4 Implementación en R

prueba <- t.test(temperatura, mu = 70)
prueba
## 
##  One Sample t-test
## 
## data:  temperatura
## t = 3.5935, df = 11, p-value = 0.004218
## alternative hypothesis: true mean is not equal to 70
## 95 percent confidence interval:
##  70.58126 72.41874
## sample estimates:
## mean of x 
##      71.5

18.4.1 Extraer p-valor

prueba$p.value
## [1] 0.004217883

18.4.2 Decisión con \(\alpha = 0.05\)

alpha <- 0.05

if(prueba$p.value <= alpha){
  "Se rechaza H0"
} else {
  "No se rechaza H0"
}
## [1] "Se rechaza H0"

18.6 Simulación

Simulamos p-valores bajo \(H_0\), es decir, cuando la media verdadera es 70.

set.seed(123)

B <- 1000
pvalores <- numeric(B)

for(i in 1:B){
  muestra <- rnorm(12, mean = 70, sd = 2)
  pvalores[i] <- t.test(muestra, mu = 70)$p.value
}

hist(pvalores,
     col = "lightblue",
     border = "white",
     main = "Distribución de p-valores bajo H0",
     xlab = "p-valor")
abline(v = 0.05, col = "red", lwd = 2)

18.6.1 Proporción de rechazos con \(\alpha = 0.05\)

mean(pvalores <= 0.05)
## [1] 0.044

Esta proporción aproxima la tasa de error tipo I.

18.7 Ejercicio propuesto

En un laboratorio se evalúa si el tiempo promedio de carga de una batería es de 120 minutos:

tiempo_carga <- c(118, 121, 119, 122, 120, 123, 119, 121, 122, 120)

Realice:

  2. Ejecute una prueba t.

  4. Tome una decisión con \(\alpha = 0.05\).
  5. Explique qué significaría cometer error tipo I en este caso.

18.8 Caso real (ingeniería)

En ingeniería civil, cometer un error tipo I podría implicar rechazar un lote de material que sí cumple especificaciones.

En ingeniería eléctrica, podría significar declarar inestable un sistema que realmente opera correctamente.

En ingeniería industrial, podría llevar a modificar un proceso que no requería ajuste.

En energías renovables, podría interpretarse erróneamente que un sistema produce menos de lo esperado cuando la evidencia no es suficiente.

18.9 Conclusión

El p-valor y los errores de decisión son conceptos centrales en la interpretación de pruebas de hipótesis. Una conclusión estadística debe acompañarse siempre de una interpretación técnica cuidadosa.
