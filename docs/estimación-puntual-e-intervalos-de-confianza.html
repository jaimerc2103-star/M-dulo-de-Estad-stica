15 Estimación puntual e intervalos de confianza

15.1 Motivación ingenieril

En la Unidad 14 se estudió que la inferencia estadística permite obtener conclusiones sobre una población usando información de una muestra. En esta unidad se aborda una pregunta central:

¿Cómo estimar un valor poblacional desconocido usando datos muestrales?

En ingeniería esta situación aparece constantemente.

Ejemplos:

  • En ingeniería civil se desea estimar la resistencia promedio del hormigón de toda una obra, pero solo se ensayan algunas probetas.
  • En ingeniería eléctrica se desea estimar el voltaje promedio de una red, pero solo se dispone de un conjunto limitado de mediciones.
  • En ingeniería industrial se desea estimar el porcentaje de piezas defectuosas de toda una producción, pero solo se inspecciona una muestra.
  • En energías renovables se desea estimar la generación promedio diaria de una planta solar a partir de algunos registros.

La estimación estadística permite responder estas preguntas de dos maneras:

  1. Mediante un solo valor: estimación puntual.
  2. Mediante un rango de valores: intervalo de confianza.

15.2 Resultados de aprendizaje

Al finalizar esta unidad, el estudiante será capaz de:

  1. Comprender el concepto de estimación puntual.
  2. Identificar estimadores para la media, proporción y varianza.
  3. Calcular estimaciones puntuales manualmente.
  4. Comprender el error estándar.
  5. Interpretar el Teorema Central del Límite de forma intuitiva.
  6. Construir intervalos de confianza para la media.
  7. Construir intervalos de confianza para una proporción.
  8. Verificar cálculos manuales utilizando R.
  9. Simular intervalos de confianza.
  10. Aplicar estimación estadística en problemas de ingeniería.

15.3 Concepto de estimación

La estimación consiste en utilizar información muestral para aproximar un parámetro poblacional desconocido.

La idea general es:

\[ \text{Estadístico muestral} \longrightarrow \text{Estimación del parámetro poblacional} \]

Por ejemplo:

\[ \bar{x} \longrightarrow \mu \]

\[ \hat{p} \longrightarrow p \]

\[ s^2 \longrightarrow \sigma^2 \]

15.4 Estimación puntual

Una estimación puntual es un único valor calculado a partir de una muestra y utilizado para aproximar un parámetro poblacional.

Ejemplos:

Parámetro poblacional Estimador puntual
Media poblacional \(\mu\) Media muestral \(\bar{x}\)
Proporción poblacional \(p\) Proporción muestral \(\hat{p}\)
Varianza poblacional \(\sigma^2\) Varianza muestral \(s^2\)

15.5 Ejemplo cotidiano

Suponga que una persona desea conocer el peso promedio de todos los sacos de arroz producidos por una fábrica en un día. Revisar todos los sacos puede ser costoso. Entonces toma una muestra de 5 sacos y calcula el promedio.

Si los pesos son:

\[ 49.8,\ 50.1,\ 50.0,\ 49.9,\ 50.2 \]

el promedio muestral sirve como estimación puntual del peso promedio poblacional.

15.6 Media muestral como estimador puntual

La media muestral se calcula mediante:

\[ \bar{x}=\frac{1}{n}\sum_{i=1}^{n}x_i \]

Donde:

  • \(\bar{x}\): media muestral.
  • \(x_i\): cada observación.
  • \(n\): tamaño de la muestra.

15.7 Ejemplo resuelto 1: resistencia de hormigón

En una obra se ensayan 6 probetas de hormigón y se obtienen las siguientes resistencias en MPa:

\[ 25,\ 27,\ 26,\ 28,\ 24,\ 26 \]

Estimar puntualmente la resistencia promedio del hormigón.

15.8 Solución manual

15.8.1 Paso 1: identificar los datos

\[ x_1=25,\ x_2=27,\ x_3=26,\ x_4=28,\ x_5=24,\ x_6=26 \]

\[ n=6 \]

15.8.2 Paso 2: aplicar la fórmula

\[ \bar{x}=\frac{25+27+26+28+24+26}{6} \]

15.8.3 Paso 3: sumar

\[ 25+27+26+28+24+26=156 \]

15.8.4 Paso 4: dividir

\[ \bar{x}=\frac{156}{6} \]

\[ \bar{x}=26 \]

15.8.5 Interpretación

La estimación puntual de la resistencia promedio poblacional es:

\[ 26\text{ MPa} \]

15.9 Verificación en R

resistencia <- c(25, 27, 26, 28, 24, 26)

mean(resistencia)
## [1] 26

15.10 Proporción muestral como estimador puntual

Cuando se estudia una característica del tipo éxito/fracaso, se utiliza la proporción muestral:

\[ \hat{p}=\frac{x}{n} \]

Donde:

  • \(x\): número de casos favorables.
  • \(n\): tamaño de la muestra.
  • \(\hat{p}\): proporción muestral.

15.11 Ejemplo resuelto 2: piezas defectuosas

En una muestra de 80 piezas producidas, 6 resultan defectuosas. Estimar la proporción poblacional de piezas defectuosas.

15.12 Solución manual

\[ x=6 \]

\[ n=80 \]

\[ \hat{p}=\frac{6}{80} \]

\[ \hat{p}=0.075 \]

\[ \hat{p}=7.5\% \]

15.12.1 Interpretación

La estimación puntual de la proporción de piezas defectuosas es 7.5%.

15.13 Verificación en R

defectuosas <- 6
total <- 80

p_hat <- defectuosas / total
p_hat
## [1] 0.075

15.14 Error de estimación

Una estimación puntual puede estar cerca o lejos del verdadero parámetro poblacional. La diferencia se conoce como error de estimación.

Para la media:

\[ Error = \bar{x}-\mu \]

En la práctica, normalmente \(\mu\) es desconocida. Por eso se usan intervalos de confianza para expresar la incertidumbre.

15.15 Error estándar

El error estándar mide la variabilidad esperada de un estadístico muestral entre diferentes muestras.

Para la media, si se conoce \(\sigma\):

\[ SE=\frac{\sigma}{\sqrt{n}} \]

Si no se conoce \(\sigma\), se utiliza \(s\):

\[ SE=\frac{s}{\sqrt{n}} \]

15.16 Ejemplo resuelto 3: error estándar

Suponga que una muestra de 25 mediciones de voltaje tiene desviación estándar muestral:

\[ s=4\text{ V} \]

Calcular el error estándar.

15.17 Solución manual

\[ SE=\frac{s}{\sqrt{n}} \]

\[ SE=\frac{4}{\sqrt{25}} \]

\[ SE=\frac{4}{5} \]

\[ SE=0.8 \]

15.17.1 Interpretación

El error estándar de la media es 0.8 V. Esto indica la variabilidad esperada de la media muestral entre muestras similares.

15.18 Verificación en R

s <- 4
n <- 25

SE <- s / sqrt(n)
SE
## [1] 0.8

15.19 Teorema Central del Límite

El Teorema Central del Límite establece que, si se toman muchas muestras de tamaño suficientemente grande de una población, la distribución de las medias muestrales tiende a aproximarse a una distribución normal, incluso si la población original no es normal.

Esto es muy importante porque permite construir intervalos de confianza y pruebas de hipótesis usando la distribución normal o t de Student.

15.20 Interpretación intuitiva

Si se toma una sola muestra, su media puede variar. Pero si se toman muchas muestras:

  • cada muestra tiene su propia media,
  • las medias muestrales se agrupan alrededor de la media poblacional,
  • mientras mayor sea el tamaño muestral, menor será la variabilidad de esas medias.

15.21 Simulación del Teorema Central del Límite

Simulamos una población no normal y luego tomamos muchas muestras.

set.seed(123)

poblacion <- rexp(10000, rate = 0.2)

hist(poblacion,
     col = "lightblue",
     border = "white",
     main = "Población original no normal",
     xlab = "Valores")

15.22 Distribución de medias muestrales

set.seed(123)

medias <- replicate(1000, mean(sample(poblacion, size = 30)))

hist(medias,
     col = "lightgreen",
     border = "white",
     main = "Distribución de medias muestrales",
     xlab = "Media muestral")

15.22.1 Interpretación

Aunque la población original no es normal, la distribución de las medias muestrales se aproxima a una forma normal.

15.23 Intervalos de confianza

Una estimación puntual entrega un solo valor. Sin embargo, ese valor puede variar de una muestra a otra.

Un intervalo de confianza proporciona un rango de valores dentro del cual se espera que se encuentre el parámetro poblacional.

La forma general es:

\[ \text{Estimación} \pm \text{Margen de error} \]

15.24 Interpretación correcta

Un intervalo de confianza del 95% no significa que haya 95% de probabilidad de que el parámetro esté dentro de un intervalo ya calculado.

La interpretación correcta es:

Si se repitiera el proceso de muestreo muchas veces, aproximadamente el 95% de los intervalos construidos contendrían el verdadero parámetro poblacional.

15.25 Intervalo de confianza para la media con \(\sigma\) conocida

Cuando se conoce la desviación estándar poblacional \(\sigma\), se utiliza:

\[ IC=\bar{x}\pm Z_{\alpha/2}\frac{\sigma}{\sqrt{n}} \]

Donde:

  • \(\bar{x}\): media muestral.
  • \(Z_{\alpha/2}\): valor crítico de la normal estándar.
  • \(\sigma\): desviación estándar poblacional.
  • \(n\): tamaño de muestra.

Para un 95% de confianza:

\[ Z_{\alpha/2}=1.96 \]

15.26 Ejemplo resuelto 4: intervalo con sigma conocida

En una planta de producción se obtiene una muestra de 36 piezas. El peso promedio muestral es:

\[ \bar{x}=50.2\text{ kg} \]

Se conoce que la desviación estándar poblacional es:

\[ \sigma=1.8\text{ kg} \]

Construir un intervalo de confianza del 95% para el peso promedio poblacional.

15.27 Solución manual

15.27.1 Paso 1: identificar datos

\[ \bar{x}=50.2 \]

\[ \sigma=1.8 \]

\[ n=36 \]

\[ Z=1.96 \]

15.27.2 Paso 2: calcular error estándar

\[ SE=\frac{\sigma}{\sqrt{n}} \]

\[ SE=\frac{1.8}{\sqrt{36}} \]

\[ SE=\frac{1.8}{6} \]

\[ SE=0.30 \]

15.27.3 Paso 3: calcular margen de error

\[ ME=Z\cdot SE \]

\[ ME=1.96(0.30) \]

\[ ME=0.588 \]

15.27.4 Paso 4: construir intervalo

\[ IC=50.2\pm0.588 \]

Límite inferior:

\[ LI=50.2-0.588=49.612 \]

Límite superior:

\[ LS=50.2+0.588=50.788 \]

15.27.5 Resultado

\[ IC_{95\%}=(49.612,\ 50.788) \]

15.27.6 Interpretación

Con 95% de confianza, el peso promedio poblacional se encuentra entre 49.612 kg y 50.788 kg.

15.28 Verificación en R

xbar <- 50.2
sigma <- 1.8
n <- 36
z <- qnorm(0.975)

SE <- sigma / sqrt(n)
ME <- z * SE

LI <- xbar - ME
LS <- xbar + ME

c(LI = LI, LS = LS)
##       LI       LS 
## 49.61201 50.78799

15.29 Intervalo de confianza para la media con \(\sigma\) desconocida

En la práctica, casi nunca se conoce \(\sigma\). Por eso se utiliza la desviación estándar muestral \(s\) y la distribución t de Student.

\[ IC=\bar{x}\pm t_{\alpha/2,n-1}\frac{s}{\sqrt{n}} \]

Donde:

  • \(t_{\alpha/2,n-1}\): valor crítico t.
  • \(n-1\): grados de libertad.
  • \(s\): desviación estándar muestral.

15.33 Intervalo de confianza para una proporción

Cuando se desea estimar una proporción poblacional, se usa:

\[ IC=\hat{p}\pm Z_{\alpha/2}\sqrt{\frac{\hat{p}(1-\hat{p})}{n}} \]

Donde:

  • \(\hat{p}\): proporción muestral.
  • \(n\): tamaño de muestra.
  • \(Z_{\alpha/2}\): valor crítico normal.

15.37 Simulación de intervalos de confianza

Simulamos 100 intervalos de confianza para observar cuántos contienen la media poblacional verdadera.

set.seed(123)

mu <- 100
sigma <- 15
n <- 25
B <- 100

LI <- numeric(B)
LS <- numeric(B)

for(i in 1:B){
  muestra <- rnorm(n, mean = mu, sd = sigma)
  xbar <- mean(muestra)
  s <- sd(muestra)
  tcrit <- qt(0.975, df = n-1)
  ME <- tcrit * s / sqrt(n)
  LI[i] <- xbar - ME
  LS[i] <- xbar + ME
}

contiene <- LI <= mu & LS >= mu
mean(contiene)
## [1] 0.95

15.45 Resumen de la unidad

La estimación puntual permite aproximar un parámetro poblacional usando un único valor muestral, como la media o la proporción. Sin embargo, debido a la variabilidad muestral, es necesario acompañar la estimación con una medida de incertidumbre.

Los intervalos de confianza proporcionan un rango plausible para el parámetro poblacional. En ingeniería, son esenciales para comunicar resultados con rigor técnico y tomar decisiones fundamentadas.
